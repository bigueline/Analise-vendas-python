# Análise de vendas com Python

Projeto prático de ADS para analisar vendas armazenadas em SQLite.

## Objetivo
Preparar os dados, analisar as vendas e apresentar resultados em gráficos.

## Tecnologias previstas
Python, SQLite, Pandas, Matplotlib e Seaborn.

Estrutura inicial criada. Desenvolvimento em andamento.
